# Konze 🗓️

### [Live Demo](https://hemant-khadun.github.io/konze/) 

Konze is a smart holiday planning tool that helps you maximize your time off by strategically planning around public holidays and remote work locations.

## 🌟 Features

### Bridge Day Detection
- Automatically identifies potential "bridge days" between holidays and weekends
- Example: When a public holiday falls on Thursday, Konze suggests taking Friday off to create a 4-day weekend

### Remote Location Planning
- Set and track holidays for multiple locations
- Perfect for remote workers or distributed teams
- Cross-reference holidays between your local and remote locations
- Example: If Thursday is a local holiday and Friday is a holiday in your remote location, Konze suggests taking Monday off for maximum efficiency

## 🚀 Getting Started

1. Visit [Konze](https://hemant-khadun.github.io/konze/)
2. Set your primary location to view local holidays
3. (Optional) Add remote locations to view their holidays
4. Konze will automatically highlight potential bridge days and optimization opportunities
